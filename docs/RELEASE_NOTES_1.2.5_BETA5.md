# SleepDown 课程表 1.2.5 Beta5

- 课程快捷菜单新增「编辑单节课」，原编辑入口更名为「快速编辑模式」。菜单收回后再展开编辑器，长按卡片先下沉，回弹与菜单同步出现。
- 编辑和复制共用课程编辑器及背景模糊。先播放外壳形变，外壳和背景停稳后再加载表单、逐行进入，减少动画期间的卡顿；关闭立即卸载表单，外壳保留打开时的宽窄方向。
- 复制课程仍可选择单周或全部周，并重新选择时间；保存成功后飞向新课程位置，必要时滚动课表显示目标。
- 快速编辑移动、缩放后的邻卡涟漪在课程首次落地时开始，减少等待感。
- 接入新的顶栏渐变模糊，模糊半径连续减小；缓存课程轮廓光渐变，减少滑动时的重复创建。
- 编辑器顶栏改为模糊弹窗与表单内容，调整展开形变并加强首页编辑、导入弹窗的模糊效果；首页全屏模糊随动效轻微压暗，让弹窗更突出。表单布局与外壳运动分开进行。
- 继续优化左右翻页，避免滑动中途重建课表；玻璃临时卸载时保留卡片颜色、轮廓光与阴影。
- 修复课程点击和长按被空白区域手势抢走的问题；菜单上方空间不足时从卡片下方弹出，快速编辑角标保持贴边并使用圆润端点。
- 个性化弹窗采用相同的轻微形变，先展开外壳再显示表单，微调紧凑滑块的大小并缩小开关；优化中心弹窗的背景与玻璃采样开销。
- 课程卡片的主题色轮廓光延伸至顶部和两侧，采用柔和的连续渐变，消除多层描边的分层感；浅色壁纸下加深主题色并减弱白光，去掉课程快捷菜单与教务页灵动岛的外投影。
- 教务网页兼容和渲染继续参考 Nexio，渐变模糊保留 SleepDown 原来的图层挂载和遮罩算法。网页顶部改为多行取色，融合成一个平滑变化的主题色，减轻单行文字与白边的干扰；快捷菜单的「移除课程」图标和文字统一为红色。
- 完善教务网页的「手机版 / 电脑版」切换：电脑版在网页脚本运行前设置宽视口，并按实际窗口宽度匹配缩放；拦截网站重复设置的视口，改善老门户页面显示不全和登录弹窗裁切的问题。
- 纳入通知修复 PR #32：补齐课程开始、课间和结束等边界刷新，恢复丢失的提醒调度，并修正通知图标对风格和明暗设置的跟随。

特别感谢 [@HaoZai000](https://github.com/HaoZai000)（[NexioSchedule](https://github.com/HaoZai000/NexioSchedule) 作者）提供渐变模糊、电脑版视口适配方案与渲染链路参考。
