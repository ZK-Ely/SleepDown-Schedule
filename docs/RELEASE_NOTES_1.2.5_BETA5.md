# SleepDown 课程表 1.2.5 Beta5

- 课程快捷菜单新增「编辑单节课」，原编辑入口更名为「快速编辑模式」。菜单收回后再展开编辑器，长按卡片先下沉，回弹与菜单同步出现。
- 编辑和复制共用课程编辑器及背景模糊。弹窗按课程所在方向拉伸展开，尾部轮廓随后贴合完整弹窗。
- 复制课程仍可选择单周或全部周，并重新选择时间；保存成功后飞向新课程位置，必要时滚动课表显示目标。
- 快速编辑移动、缩放后的邻卡涟漪在课程首次落地时开始，减少等待感。
- 接入新的顶栏渐变模糊，模糊半径连续减小；缓存课程轮廓光渐变，减少滑动时的重复创建。
- 编辑器顶栏改为模糊弹窗与表单内容，增强展开形变及首页编辑、导入弹窗的模糊效果；提前完成表单布局，减少打开末尾的停顿。
- 继续优化左右翻页，避免滑动中途重建课表；玻璃临时卸载时保留卡片颜色、轮廓光与阴影。
- 修复个性化分区裁切滑块进入动画、教务网页额外离屏渲染的问题；快捷菜单的「移除课程」图标和文字统一为红色。
- 纳入通知修复 PR #32：补齐课程开始、课间和结束等边界刷新，恢复丢失的提醒调度，并修正通知图标对风格和明暗设置的跟随。

特别感谢 [@HaoZai000](https://github.com/HaoZai000)（[NexioSchedule](https://github.com/HaoZai000/NexioSchedule) 作者）提供新的渐变模糊实现与渲染链路参考。
